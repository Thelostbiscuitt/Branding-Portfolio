( SCROLL DOWN )
OVERVIEW

A production-ready Telegram assistant built on OpenRouter. Layered memory you can inspect and erase, Tavily web search, a local book library, image generation and cost visibility — all inside one conversation.

SERVICES
  • Telegram assistant (Python)
  • Layered memory system
  • OpenRouter multi-model wiring
  • Tavily web search
  • Local book library
THE CHALLENGE

Assistants that forget, or won't say what they know

Most chat assistants either remember nothing useful or remember everything with no way to check it. For real daily use, memory has to be inspectable — and erasable on demand, not buried in a settings tree.

Cost visibility

API-based assistants hide their running costs. Biscuit surfaces them in the conversation, so usage is a decision, not a surprise.

APPROACH

One conversation, layered memory

Memory is structured in layers that can be opened, read and wiped from inside the chat itself. Web search (Tavily), a local book library and image generation plug into the same interface — no modes to switch, no dashboards to learn.

DELIVERABLES
  • Telegram assistant (Python)
  • Layered memory system
  • OpenRouter multi-model wiring
  • Tavily web search
  • Local book library
  • Image generation
  • Cost visibility layer
RESULT

Production-ready, in daily use.

Shipped as a working product rather than a demo — the stack, memory model and cost controls all run live.

QUESTIONS WE ACTUALLY GET
What did you deliver?

The full assistant: memory system, search, library, image generation and cost visibility, running on Telegram.

Why Telegram?

It is where the conversation already happens — no new app to adopt, the assistant lives inside an existing habit.

Can I try it?

Ask — access is granted per person while the product is in active development.

Kitchens waste what they can't see

Ingredients expire untracked and meal decisions get made from memory. Recipe apps assume you shop for a plan; real kitchens cook from what exists.

Inventory apps die of friction

Dedicated inventory tools lose to the dreaded data-entry step. If updating stock takes effort, it stops happening by week two.

APPROACH

Conversation as the interface

Everything runs through plain chat commands: add what you bought, say what expired, ask what to cook. Gemini suggests across 40+ cuisines from the live inventory — the interface cost of telling the truth about your kitchen is zero.

DELIVERABLES
  • Telegram assistant
  • Ingredient + expiry tracking
  • Suggestion engine (Gemini)
  • 40+ cuisine coverage
  • Conversational UX design
RESULT

Zero forms, zero dashboards.

The whole product is a chat — inventory stays current because updating it costs a sentence.

QUESTIONS WE ACTUALLY GET

End-to-end: the assistant, the inventory model and the suggestion engine, designed and shipped by one pair of hands.

How is this different from a recipe app?

Recipe apps start from dishes and send you shopping. Chef4Me starts from your kitchen and closes the gap to dinner.

Is it live?

It runs on Telegram — ask for access.

( SCROLL DOWN )
OVERVIEW

A complete operations rebuild for an immigration firm's relationship managers: role-scoped data, an append-only audit trail enforced at the database level, working-days SLA clocks and an in-browser CRS calculator.

SERVICES
  • Next.js operations portal
  • Role-scoped access (RBAC)
  • Append-only audit trail
  • Working-days SLA clocks
  • In-browser CRS calculator
THE CHALLENGE

Trust me isn't an audit trail

Compliance-sensitive operations can't run on editable logs and goodwill. Edits had to be impossible to hide — the enforcement point had to be the database, not the UI.

Deadlines measured in working days

Immigration timelines are regulatory, not aspirational. SLA clocks had to count the same calendar the authority does — working days, not vibes.

APPROACH

Enforce at the bottom, show at the top

Role-scoped data access, an append-only audit trail at the database level, working-days SLA clocks on every case, and an in-browser CRS calculator — the tools relationship managers need, none they don't.

DELIVERABLES
  • Next.js operations portal
  • Role-scoped access (RBAC)
  • Append-only audit trail
  • Working-days SLA clocks
  • In-browser CRS calculator
RESULT

Compliance you don't have to remember to do.

The trail appends, the clocks count, the roles scope — the system enforces what process used to hope for.

QUESTIONS WE ACTUALLY GET
What did you deliver?

A complete operations rebuild: portal, RBAC, database-level audit trail, SLA clocks and the CRS calculator.

Why database-level enforcement?

UI rules get bypassed; constraints don't. Compliance that matters belongs in the schema.

CAPABILITY 01 / 08 — IDENTITY SYSTEMS · VOICE · GUIDELINES

An identity is a system, not a logo.

Brand identity, editorial and graphic composition is the craft under every project — the part of the practice with the longest history. Identities are built to be used: drawn, specified and shipped with the product they belong to.

WHY IT MATTERS

A mark without specifications is a drawing.

A mark without specifications is a drawing. The identities built here are systems: mark, type, colour and voice specified tightly enough that the next person executes without guessing. That standard exists because it was tested where identity failure is expensive — inside an enterprise operation, where every inconsistent touchpoint becomes a support ticket or a compliance query.

The strongest proof is an unprompted one: a full brand-extension pitch for Leadway Pensure, one of Nigeria’s largest pension funds — identity guidelines, product redesigns, a social system and a brand voice — built on four years of operational experience inside the organisation and delivered as a live web document rather than a static deck.

QUESTIONS I ACTUALLY GET
Do you do logo-only work?
